# Labs Sesión 9 - Programación Orientada a Objetos (Java)

Repositorio que recopila el desarrollo de los laboratorios prácticos correspondientes a la **Sesión 9**, enfocados en la aplicación de los principios de la **Programación Orientada a Objetos (POO)** utilizando **Java**.

---

## Estructura del Repositorio

El proyecto está organizado en 5 módulos o laboratorios independientes (`s09lab01` al `s09lab05`), cada uno abordando un caso de estudio con sus respectivas clases, lógica de negocio, archivos ejecutables (`Main`) y documentación de solución[cite: 1]:

### s09lab01: Gestión de Clientes y Consultores
* **Clases principales:** `Cliente.java`, `Consultor.java`, `S09Lab01Main.java`[cite: 1]
* **Descripción:** Modelado de relaciones de negocio y servicios de consultoría, gestionando la interacción y atributos entre clientes y asesores.

### s09lab02: Gestión de Equipos y Jugadores
* **Clases principales:** `Equipo.java`, `Jugador.java`, `S09Lab02Main.java`[cite: 1]
* **Descripción:** Sistema de administración deportiva para gestionar planteles, integrando colecciones y atributos específicos de jugadores dentro de un equipo.

### s09lab03: Sistema de Cuestionarios y Preguntas
* **Clases principales:** `Cuestionario.java`, `Pregunta.java`, `S09Lab03Main.java`[cite: 1]
* **Descripción:** Estructura orientada a la creación y evaluación de exámenes o encuestas, manejando colecciones de preguntas vinculadas a un cuestionario general.

### s09lab04: Gestión de Álbumes y Fotografías
* **Clases principales:** `Album.java`, `Fotografia.java`, `S09Lab04Main.java`[cite: 1]
* **Descripción:** Aplicación para organizar galerías multimedia digitales, relacionando colecciones de fotografías dentro de álbumes temáticos.

### s09lab05: Órdenes de Trabajo y Pasos
* **Clases principales:** `OrdenTrabajo.java`, `Paso.java`, `S09Lab05Main.java`[cite: 1]
* **Descripción:** Automatización y seguimiento de procesos operativos, donde una orden de trabajo se compone de una secuencia ordenada de pasos a ejecutar.

---

## Tecnologías y Requisitos
* **Lenguaje:** Java (JDK 27).
* **Paradigma:** Programación Orientada a Objetos (POO) (Encapsulamiento, asociación, modelado de clases).
* **IDE sugerido:** IntelliJ IDEA.
